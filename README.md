# Waterborne Disease Early Warning System

An academic demonstration system for predicting waterborne disease outbreak risk using machine learning. Built with Streamlit, scikit-learn, and real CGWB groundwater data for Chhattisgarh, India.

> ⚠️ **This is an academic project.** Models are trained on synthetic, rule-generated labels. Results do NOT constitute validated epidemiological forecasts or confirmed outbreak data.

---

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

> **Note:** `scikit-learn==1.6.1` is pinned. The saved `.pkl` model files were serialised with this exact version. Upgrading scikit-learn will break unpickling.

### 2. Place the CGWB data file

Download the CGWB Chhattisgarh groundwater CSV and save it as:

```
data/raw/cgwb_cg_groundwater.csv
```

This enables the **Water Quality (CGWB)** page. The app runs without it — that page will show a warning.

### 3. Run the Streamlit app

```bash
streamlit run app.py
```

### 4. (Optional) Retrain models

```bash
python -m src.train_models
```

This regenerates `models/model_14d.pkl`, `models/model_30d.pkl`, and `reports/model_evaluation.json`.

## Data Provenance

The system uses **three distinct data sources**, kept strictly separate:

| Source | Field `record_origin` | Rows | Description |
|--------|----------------------|------|-------------|
| `data/dataset.csv` | `training_dataset` | 798 | Pan-India drinking-water survey data |
| `data/raw/cgwb_cg_groundwater.csv` | `cgwb_observed` | 10,350 | Real CGWB Chhattisgarh groundwater chemistry, 1961–2025 |
| Synthetic generator | `synthetic` | 1,500 | Rule-generated training data (academic scenarios) |

**Important unit differences:**
- CGWB arsenic: `mg/L` → column `arsenic_mg_l`
- Training dataset arsenic: `µg/L` → column `arsenic_ug_l`
- CGWB nitrate: as nitrogen `mgN/L` → column `nitrate_n_mg_l`
- Training dataset nitrate: as full nitrate `mg/L` → column `nitrate_mg_l`

These datasets are **never merged** — they have different schemas, measurement methods, and geographic scopes.

## Machine Learning Models

### Dual-horizon design

| Horizon | Target diseases | Rationale |
|---------|----------------|-----------|
| **14-day** | Cholera, Dysentery, Leptospirosis | Short incubation; fast-onset |
| **30-day** | Typhoid, Giardiasis, Hepatitis A, Hepatitis E | Longer incubation; slow-onset |

### Features (40 total)

- 34 numeric features (water quality, environmental, sanitation, demographic, engineered composite scores)
- 6 categorical features (region, season, water_source, water_treatment, handwashing_practice, gender)

### Pipeline

```
ColumnTransformer(
    StandardScaler  → NUMERIC_FEATURES (34),
    OrdinalEncoder  → CATEGORICAL_FEATURES (6)
)  →  GradientBoostingClassifier
```

### Performance (against synthetic labels)

| Horizon | Best model | Macro F1 | ROC-AUC |
|---------|-----------|----------|---------|
| 14-day  | GradientBoosting | ~0.89 | ~0.97 |
| 30-day  | GradientBoosting | ~0.83 | ~0.95 |

> ⚠️ These metrics measure fit to **synthetic rule-generated labels** — they do NOT reflect real-world disease forecasting accuracy.

### Synthetic label rules

Disease labels are assigned deterministically by documented epidemiological thresholds (WHO 2017, IS:10500:2012). Examples:

- **Cholera**: fecal_coliform > 50 MPN/100mL AND turbidity > 4 NTU AND residual_chlorine < 0.2 mg/L
- **Leptospirosis**: flooding = 1 AND rainfall > 150 mm AND turbidity > 5 NTU
- **Typhoid**: nitrate > 30 mg/L AND fecal_coliform > 20 AND sewage_treatment < 40%

See `src/synthetic_data_generator.py` → `DISEASE_RULES` for complete definitions.

## IS:10500:2012 Reference Limits

Key BIS Indian drinking water standards used for violation flags:

| Parameter | Acceptable | Max Permissible |
|-----------|-----------|----------------|
| pH | 6.5–8.5 | 6.5–8.5 |
| TDS | 500 mg/L | 2000 mg/L |
| Nitrate | 45 mg/L | 45 mg/L |
| Fluoride | 1.0 mg/L | 1.5 mg/L |
| Iron | 0.3 mg/L | 1.0 mg/L |
| Arsenic | 0.01 mg/L | 0.05 mg/L |
| Total Hardness | 200 mg/L | 600 mg/L |
